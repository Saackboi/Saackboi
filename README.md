### About Me

**Full-Stack Developer and Software Engineer** focused on building scalable solutions and automating infrastructure. I bring practical experience in corporate environments, transforming complex requirements into robust and efficient architectures. Currently, I am complementing my professional career as an advanced student in the Software Development and Management Bachelor's program at Universidad Tecnológica de Panamá.

* **Software Engineering:** Project lifecycle management, emphasizing planning, structured technical documentation, and testing strategies.
* **Full-Stack Development:** Specialized in robust architectures with **.NET Web API** and reactive frontends in **Angular**, applying best practices and complex state management with **NgRx**.
* **AI & Automation:** Implementation of **AI agents** as strategic support in development, and workflow automation using **n8n**.
* **Infrastructure & Ops:** Server administration in **Linux** environments, agile container deployment with **Docker**, and secure network management with **Cloudflare Tunnels**.
* **Agile Solutions:** Business application development and internal process automation using **Power Apps**.
